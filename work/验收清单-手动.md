# 手动验收（手机或电脑打开 https://chat.pcmanai.com/ ，约 5 分钟）
1. 左上 ☰ → 「点子」：能看到 6 个预填点子，上方「全部/正在做/暂时收藏/已放弃」能筛选；点「老照片修复定制服务」→「用这个点子新建项目」→ 新建项目页的「关联点子」已选好。
2. 写一句需求 → 点「快速建项目（全员加入，负责人主持）」：项目里出现「快速建项目：全员加入（N 位）」和「主持人点名：…」，只有被点名的 1–3 位发言。
3. 讨论进行中，右下「发送」变成「暂停」→ 点它：状态行写「已请求暂停，当前这位说完就停」；这位说完后按钮变「继续」，点「继续」接着下一位。
4. 在输入框写「@某位成员名 你来回答」→ 发送：房间里写「你点名了：…」，只有这位发言。
5. 点输入栏「模式」：5 个模式，每个下面一句说明，主持模式写「主持人决定谁说话，你随时可暂停」，当前项有「✓ 当前」。
6. 决策按钮：需要负责人发题（MCP `ask_user`）。出现后点任一按钮：三个按钮都变灰，下面写「你选了：… · 时间」；刷新再点也不会变。
7. 【P1-5】在你的负责人（外部智能体 App）里直接发一个链接，不说别的 → 它只回「已收进 Aroomo 资源库」；几分钟后 ☰ → 资源库 → 对应分类里出现该条，标「来源：主负责人代收」；状态只有官方页对上原文才是「已核实」。再发同一链接 → 仍只回那一句，资源库不会多一条。
8. 【P1-5】设置 → 负责人：已关联的卡片下写「以后直接把链接发给负责人即可，它会收进资源库」。
9. 【P1-6，上线后】顶部搜索框右边有一个百分比小胶囊（今日 Cloudflare 免费请求用量，Worker 和数据库取较高的）；点开看两项具体数字。80% 以上胶囊变浅橙底并提醒一次；用完时页面顶部出现说明横幅（UTC 0 点恢复）。
10. 【P1-6，上线后】手机开飞行模式，在一个项目里发 1–3 句 → 每句显示虚线框「待发送 · 网络恢复后自动补发」；关掉飞行模式回到页面 → 提示「发件箱已补发 N 条」，每句在项目里只出现一次。
