# 待评审：AI 团队群聊 Phase 3 界面设计（样稿第 1 版）

## 产品
用户把散落各处的 AI 模型（每个模型一张「AI成员」卡，同一模型可从多个「来源」调用：官方 API、中转站、公益站、网页、本地显卡）拉进按项目分的群，Hark 当负责人派工，成员互相审查。额度用完自动换来源或换人（接班）。另有：擅长/不擅长标签（入职按社区评价，之后按互评+用户打分迭代）、口碑分、额度账本与项目预算、招聘（羊毛监控发现免费模型 → 试用 → 到期决定留不留）、权限分级、敏感内容不发中转站、审计日志、项目共享记忆、完成推送 Telegram/Bark、朗读与语音发任务、同题并排对比归档、工具库（沙盒/显卡/电话号码等，不算成员）。

## 用户
一个人用；主要用 iPhone；**有眼疾，不能长时间看屏**，要大字、高对比、少看屏、能语音。品牌色用户指定：珊瑚色。

## 设计决定（请重点挑这些）
1. 风格：账本式安静界面（灰阶外壳、无阴影、数字等宽右对齐），颜色只给「要你决定的东西」：主按钮、派工卡左边框、到期提醒、选中态。
2. 珊瑚色阶 50–950，400 = #FF7F50。主按钮 = 珊瑚 400 填充 + 墨色字 #141413（实测 ≈7:1；白字只有 2.5:1）。珊瑚色文字浅色用 800 #8F2B18（白底 8.31:1），深色用 300 #FFAD90（深底 10.2:1）。焦点环 600 #D25E39（3.89:1）。
3. 正文 #1A1A19（17.4:1），次要文字 #52524E（7.85:1，两档都过 AAA 7:1）；底 #F6F6F4，卡片白。危险色 #B42318（与珊瑚同属红橙系，靠图标+文字区分）。
4. 一级导航 5 项：群聊 / AI成员（招聘是它的 tab）/ 工具库 / 对比归档 / 设置。项目不占一级。
5. 群聊：桌面三栏（导航 248 / 消息流 ≤860，正文 17px / 右栏 336：项目预算条 + 成员列表，每人一根当前来源额度条）。派工卡是唯一带珊瑚左边框的卡，含「就这样开始 / 换人」。接班与换来源是灰底系统行。手机：去右栏，标题下一条「预算剩 83% · 1 位已接班」状态条，右上成员按钮，底部 56px 珊瑚话筒（按住说话）。
6. 成员资料卡：页头（头像 / 模型名 + ID + 一句话定位 / 口碑 4.3 大数 + 「23 次评分：你 9 · 互评 14」+ 派活按钮）；左列：擅长（每条标签带来源小框：社区评价 / 实测 / 互评 / 你打分 + 一句证据）→ 不擅长 → 来源表（顺序、额度条、状态 pill、近 14 天可用率格）；右列：口碑构成 4 条、能用的工具、履历。
7. 名册：tab（在职/试用中/候选/没留下的），先放「等你决定」两块（试用到期、新候选），再放在职表格。
8. 设置：一类一屏；权限与安全页 = 动作分级表（直接做 / 预算内直接做 / 先问我）+ 敏感内容开关与拦截示例 + 审计日志（三筛选 + 导出）。
9. 借鉴：OpenRouter 模型页 Providers 表（来源表）、Upwork JSS + Fiverr 评分构成（口碑）、Greenhouse 盲评（互评）、Linear 委派（派工）、Vercel 50/75/100% 告警（预算）、PagerDuty 升级层级（接班）、LMArena 并排投票（对比）、GitHub 细粒度权限 + Notion 审计筛选（设置）。


## 第一批实际上线时的补充约束（用户硬性要求，也请评）
- 头像 = 品牌 Logo（不是首字母），外圈一圈额度环（像电量），右下绿/红状态点并在旁边写文字。
- 消息：头像在左，右侧上方「模型名（角色）」如 gpt-oss-120b（程序员），下方气泡，气泡底色 = 该品牌主色（Grok 黑、负责人 Hark 黑），字色按对比度自动选黑/白；深色模式下近黑色品牌改为描边气泡。
- 手机优先，正文 19px，点按区 ≥44px，底部 4 个 tab：对话 / 项目 / AI成员 / 工具库；顶部全局搜索框。
