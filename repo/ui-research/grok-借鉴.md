# Grok App 借鉴清单（groupchat-v3 界面重做底子）

日期：2026-10-23 · 写给：接手开发者 / 用户验收
用户原话：界面「要当成正规应用程序来做，只是用网页呈现」；以 Grok App（grok.com + iOS App）整体界面为底子，再融入用户需求。

> 本次用到的技能：hub-coding-agent、hub-graphic-design、frontend-design、emil-design-skills（mobile-native）、design-taste 记忆（Taste for Makers、visual-rules、design-gate-loop）。
> 借鉴的规范：①「Every fix ships with the reason … Never disable zoom」「Input font size 16px at the minimum」「theme-color per color scheme」（emil mobile-native）②「不由用户触发的动效只做一处有编排的；响应用户操作、说明变化的动效可以有」（frontend-design）③「不测不报数、门禁失败就修到全绿」（design-gate-loop）④「Colour goes on data, not chrome」（taste-skill app-screens）⑤ Paul Graham「删掉装饰还成立吗」。

## 借鉴清单
标记：**照搬** = 直接用 Grok 做法；**改** = 因用户需求改；**不用** = 明确不借。

### 1. 导航结构
| Grok 做法 | 处理 | 我们怎么做 / 理由 |
|---|---|---|
| 单一主界面，无底部 tab；历史/项目从左侧抽屉滑出（手机 84% 宽，桌面常驻侧栏） | **照搬** | 左抽屉：品牌 + 「新项目」大按钮 → 四个入口（对话/项目/AI成员/工具库）→ 最近项目列表（带状态小框）→ 外观设置。手机从屏幕左边缘右滑或点 ☰ 打开，左滑或点遮罩关闭；≥1000px 常驻 288px。原来的底部四个按钮取消（底部只留输入栏，跟 Grok 一样）。 |
| 顶栏：左 ☰ · 中模式胶囊 · 右「新对话」 | **改** | 中间放**全局搜索胶囊**（用户硬需求「顶部搜索框」），右边是「新项目」✎。 |
| Cmd+K 搜索弹窗 | **改** | 搜索常驻顶栏（低视力不用记快捷键）；桌面也支持 `/` 聚焦搜索。 |
| 「新对话在发出第一句前不建空会话」 | **照搬** | 原逻辑本来就是发出需求才建项目。 |

### 2. 输入栏（Composer）
| Grok 做法 | 处理 | 我们怎么做 |
|---|---|---|
| 底部大圆角胶囊（圆角 24、表面色、1px 边），随内容长高到 5 行 | **照搬** | 圆角 26，最小高 56；文字 19px（用户 ≥19px，且 ≥16px 防 iOS 放大）。 |
| 左边 + 菜单（上传/技能/连接器），打开后变 × | **改** | + 菜单放本产品的动作：新项目（Hark 推荐分工）、成员与角色、打分、成员互评。不做上传（后端不支持）。 |
| 右侧模式胶囊（Fast/Expert…） | **改** | 模式胶囊 = 讨论模式（辩论/协作…，来自 `/api/members` 的 modes），点开底部弹层选。 |
| 发送钮：空时灰、有内容变实心白圆 | **改** | 实心**珊瑚色**圆（用户主色），墨色箭头；44×44 点按。空时灰。 |
| 话筒/语音 | **不用（本批）** | 语音发任务在第 2 批增强（⑦），本批不做；iPhone 键盘自带听写可用。 |
| 「再来一轮」 | 新增 | 输入栏左侧 ↻ 圆钮（带文字提示 aria-label），只在打开项目时可用。 |

### 3. 消息排版
| Grok 做法 | 处理 | 我们怎么做 |
|---|---|---|
| 用户消息：右对齐浅表面气泡，圆角 20、发送方一角 6 | **照搬** | 圆角 22/6，表面色。 |
| AI 回复：无气泡、全宽纯文本，无头像无名字 | **改（用户硬规矩）** | 必须「左头像（带额度圆环）+ 右上『模型名（角色）』+ 品牌色气泡」。保留 Grok 的大行距（1.7）与回合间距 24px。 |
| 回复后一行图标（复制/重来/分享/赞踩），复制成功变绿打勾 1.2s | **照搬（部分）** | 每条成员消息下有「复制」（44px 点按），成功打勾 + Toast「已复制」。赞踩不放这里——打分走原有「打分」弹层（带岗位）。 |
| 流式光标 ▍ | **改** | 后端不流式；「思考中」显示骨架气泡 + 三点脉动（尊重减少动效）。 |

### 4. 字体 / 配色
| Grok 做法 | 处理 | 我们怎么做 |
|---|---|---|
| Inter，400/600/700，正文 16 | **改** | CSP 不允许外部字体；用系统字（iPhone 苹方 / SF），字重同样只用 400/600/700；正文 19、标题 28（大标题）、次要 16、最小 14。数字等宽。 |
| 深色为主，纯黑 #000 画布，表面靠明度分层（#16181C→#1E2126→#272A2E），分割线 #2F3336，几乎无阴影 | **照搬（深色）** | 深色主题用这套。次要文字由 #71767B 提亮到 #A3A8AE（对 #000 8.3:1、对 #1E2126 6.9:1），低视力优先。 |
| 只有深色 | **改** | 用户要浅色深色都有：浅色 = Grok 浅色工作区反相（白画布、#F4F4F2 表面、发丝线 #E3E2DD、墨 #15161A）。默认跟随系统，抽屉里可选「跟随系统/浅色/深色」。 |
| 强调色：白色当强调；橙色 #FF6B35 只做少量强调 | **改** | 珊瑚 #FF7F50（用户主色）顶替「白色强调」：发送钮、主按钮、选中项、焦点环；珊瑚文字用加深档（浅 #8F2B18 / 深 #FFAD90）。Grok 本身就用暖橙做少量强调，方向一致。 |

### 5. 侧栏 / 抽屉 / 弹层
| Grok 做法 | 处理 | 我们怎么做 |
|---|---|---|
| 抽屉行高 56、选中行表面色、分组小标题（今天/之前） | **照搬** | 项目列表按「今天 / 更早」分组，选中行表面色 + 珊瑚左线（颜色之外还有加粗）。 |
| 底部弹层（模型选择、分享）：表面 #1E2126、大阴影、遮罩 .6 | **照搬** | 成员名册、成员详情、新项目、模式、打分、阵容都做成**原生感底部弹层**：顶部抓手条、可下拉关闭、标题栏吸顶、✕ 44px；动画 transform 上滑 320ms `cubic-bezier(.32,.72,0,1)`（iOS 弹层曲线）；桌面变右侧面板。 |
| 设置 = 对话框 + 左侧分组栏 | **改** | 本批不做设置页（第 3 批）；只把「外观」做成抽屉底部的分段控件，风格同 Grok 设置控件。 |

### 6. 空状态 / 加载 / 出错 / 提示
| Grok 做法 | 处理 | 我们怎么做 |
|---|---|---|
| 空状态：居中字形 + 3–4 个建议胶囊，无插画 | **改** | 居中一枚「头像+额度圆环」线稿图标（本产品的识别符号）+ 一句话 + 3 个建议胶囊（点了填进输入栏）；成员/项目/搜索为空时各有图标 + 下一步按钮。 |
| 骨架 / 占位 | **照搬** | 首屏加载：抽屉项目列表、成员列表、工具卡显示骨架条（脉动，减少动效时静止）。 |
| 连接失败显示服务器原话 | **照搬** | 所有错误用 Toast 显示后端返回的原话（替换原来的 alert），错误 Toast 红色左线 + 「出错：」文字前缀。 |
| 复制成功绿勾 Toast | **照搬** | 底部居中 Toast，3 秒自动消失，aria-live 朗读。 |

### 7. 动效
| Grok 做法 | 处理 | 我们怎么做 |
|---|---|---|
| 只动跟操作相关的：模式切换 200ms 弹簧、按下缩 0.92、复制变色 150ms | **照搬** | 按下 `:active` 缩 0.97（只用 transform）；抽屉 280ms、弹层 320ms、视图切换淡入 180ms、Toast 上浮 200ms。hover 样式只在 `(hover:hover) and (pointer:fine)` 下生效（mobile-native）。`prefers-reduced-motion` 时全部取消位移动画。 |

### 8. 「像 App」的平台层（mobile-native 条款）
`viewport-fit=cover` + 安全区；`100dvh`；去掉点按灰闪；`touch-action: manipulation`；`overscroll-behavior` 防橡皮筋穿透；按钮 `user-select:none`；**不禁止缩放**；`theme-color` 分浅深；PWA manifest（`display: standalone`、App 图标 192/512 + maskable + apple-touch-icon），iPhone「添加到主屏幕」后全屏运行。

## 用户硬规矩（全部高于 Grok）
额度圆环 + 2.5px 背景色细缝；在线彩色 / 离线黑白、无状态点；名字旁「可用/不可用/未探测」文字小框；消息左头像 + 右「模型名（角色）」+ 品牌色气泡；珊瑚强调；正文 ≥19px、点按 ≥44px；浅色深色都要；成员详情顺序不变；搜索、阵容、打分、互评、项目状态、外部成员、API 密钥区、算力卡全部保留。

## 落地后的调整（评审 + Claude Design，2026-10-23 11:xx）
- 深色画布从 Grok 的 #000 改为柔和近黑 #121211（评审 A5：纯黑对低视力眩光）；浅色白底带微弱暖色 #fbfbfa；整套前景背景统一暖中性（Claude Design「一种色调」）。
- 「再来一轮」移出输入栏，放到对话末尾（带文字）和 ＋ 菜单；外观/退出登录移进「外观与设置」弹层；抽屉加 ✕。
- 模式同时显示在项目标题下，切换有提示。错误 Toast 不自动消失。
- 去掉左边框 accent 条、输入栏渐变、骨架闪光；可点元素都是真 `<button>`。
- 评审逐条结论见 `调研报告.md` 第 10 节。
