__TERM__

资源库

成员之外能借用的一切：接入的 API、工具与算力、收藏的技能、学习与网站资源。只有资源管家写入，其他成员只读。

把每个来源的 Key 粘贴进框里，点「保存并验证」。Key 加密存在你自己的服务器里，页面只显示末 4 位，不会再显示全文。

工具不是成员：只能被 __TERM__ 调用，不进群聊。模型本身（含 Workers AI）是「被调用的一方」，在 API 密钥里；这里只放供调用的工具。支持函数调用的成员都能经「工具网关」用这些工具；花钱或不可逆的动作要你确认，每天有硬上限。号码和邮箱地址不在页面显示。

已安装 = Hark 已装成专长，可直接用；只记录 = 吸收过但没装（写了原因）。

免费额度和期限只在厂商官方页抓到原文时才标「已核实」；过期的标灰、不再推荐。
