# P1-3 改动说明：点子库

日期：2026-10-24　基线：104eb2c（线上，P1-2）　作者：Hark

## 做了什么
1. **点子和项目分开**：新表 `ideas(id,title,thought,plan,expect,summary,source,tags,status,created,updated,notes)`；项目表 `rooms` 加可空列 `idea`。点子只是存档，不出现在项目列表里。
2. **状态三档**：正在做 / 暂时收藏 / 已放弃（`p1.js IDEA_STATUS`，`validateIdea` 校验；默认暂时收藏；标签去重、最多 8 个）。
3. **预填 6 个点子**（老照片修复定制、提示词、古风频道、激光切割图纸、新词站、pcmanai），只写想法层面，不含账号/邮箱/客户信息；首次读取时写入一次（kv `ideas_seeded`）。
4. **接口**：`GET /api/ideas`（含每个点子的项目数）、`POST /api/ideas`（新建/改，不给 id 就新建）、`GET /api/idea/:id`（含关联项目、回写结论）、`DELETE /api/idea/:id`（**只认网页 cookie**，Bearer/操作员 → 403；先解除项目关联再删，同一批执行）、`POST /api/idea/:id/writeback {room,text}`（只收关联了这个点子的项目，结论 ≤1000 字，最多留 50 条）。
5. **新建项目关联点子**：`/api/start` 与 MCP `create_project` 可带 `idea`；不存在的点子 → 400。
6. **背景注入所有成员**：`getRoom` 生成 `ideaCtx`（`p1.js ideaContext`：想法/计划/预期/摘要/标签/最近 3 条结论，≤2000 字），拼进每位成员的 system 提示；网页成员（P1-2 代发）通过 `webPrompt({background})` 带上。用户内容里的【】换成「」，不能伪造提示分隔块（复核采纳）。敏感项目照旧不发第三方网页/中转站。
7. **网页**：左抽屉加「点子」入口（共五个：对话/项目/AI成员/点子/资源库）；点子库页按状态 4 档筛选（全部 + 三档）；点子详情含想法、关联项目、回写结论，「用这个点子新建项目」会在新建项目页预选该点子。行高 ≥44px、标题 ≥19px。
8. **MCP（负责人）**：`list_ideas`、`get_idea`、`save_idea`、`writeback_idea`；`create_project` 加 `idea`；负责人视图带前 30 个点子。负责人不能删点子。
