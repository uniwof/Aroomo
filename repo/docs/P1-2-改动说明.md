# P1-2 改动说明：网页成员（代发）

日期：2026-10-24　基线：f5a7657（= 线上 8208041，L1）　作者：Hark（Grok 无额度，不交接）

## 做了什么
1. **网页成员**：新连接方式 `web`（网址 `site`，可选「仅客户端型」`client`、「每天签到」`checkin`）。成员卡、成员列表、MCP `list_members`、负责人视图 `GET /api/lead/brief`（`web:true`、`via:经代发`）里都是正常成员；`caps.web=true`，**不能当负责人**（P1-1 规则沿用）。`gpt-image-2.5`（arena.ai Direct）改走网页代发队列。
2. **代发员**：「设置 → 网页代发员」登记（Hark 远程浏览器 / 用户电脑上的桌面桥接），令牌 = HMAC(ACCESS_TOKEN, `relay:<id>`)。登记、删除、"允许操作我的电脑"都只认网页 cookie；Bearer/操作员只能读列表（不含令牌）。
3. **代发队列**：派给网页成员的任务写入 `tasks(kind='web')`，提示由 `p1.js webPrompt` 生成——前情（记录末 3500 字）+ 角色 + 输出格式，**不写产品名、不写接口地址**。代发员 `GET /bridge/web/pull?relay=ID` 领取（条件更新，同一任务不会被两人领走），`POST /bridge/web/reply?relay=ID` 回传，房间里消息标「经代发 · 代发员名」。
4. **会话复用**：回传可带 `session`（https 链接或短 id），记在 `websess:<房间>:<成员>`；同一项目下次优先给同一代发员（2 分钟内留给它）并带上会话链接。
5. **10 分钟改派**：领走 10 分钟没回 → 退回队列并排除原代发员，房间里写「已改派」；第 3 次还不行 → 失败并说明。超 24 小时没人领的标失败。拉取、打开房间、每小时 cron 都会扫。
6. **签到**：`checkin:true` 的网页成员每天出现在代发员拉取结果的 `checkins` 里，`POST /bridge/web/checkin?relay=ID` 回报。
7. **仅客户端型**：只派给 `kind=desktop` 且用户在网页点过同意的代发员；桌面桥接没同意前任何任务都不领（它会操作用户电脑）。没有可用代发员时成员显示离线并写明原因。
8. **敏感项目**：网页成员来源级别为 `web`「第三方网页（经代发）」，敏感项目与中转站一样不发、写审计（复审采纳）。
9. 测试模式：测试期间登记的代发员只领测试任务；测试结束作废测试任务、删测试代发员。`POST /api/testmode/websweep {advanceMs}`（仅测试模式 + cookie）用来验证 10 分钟改派。
