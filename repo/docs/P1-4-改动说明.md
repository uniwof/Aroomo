# P1-4 改动说明：主持模式 + 快速建项目（含 N2 暂停/继续、N3 消息内决策按钮、L7 模式说明）

日期：2026-10-24　基线：4382007（线上，P1-3 fix1）　作者：Hark

## 做了什么
1. **主持模式 `host`**（第 5 种模式「主持」）：项目阵容可以很大，但每轮只由负责人点名 1–3 位发言（规则：按议题岗位排序，只在本项目成员里挑；都不匹配就取前 2 位），房间里写「主持人点名：A、B。其他成员这轮先听；想指定谁，就 @ 他。」
2. **@ 点名**（任何模式）：用户消息里写 `@成员名` 或 `@id`，本轮只请被点名的成员；房间里写「你点名了：…」。只认本项目成员；`a@b.com` 这类邮箱不算。
3. **快速建项目**：新建项目弹层加「快速建项目（全员加入，负责人主持）」按钮；接口 `POST /api/start {message, quick:true}` / MCP `create_project {quick:true}`。全员 = 除负责人、资源管家、退役、只当负责人、离线以外的所有成员（最多 20 位），角色统一新角色「成员」，模式自动 = 主持。原有「开始」照旧不强制选成员（不选就由负责人派工）。
4. **N2 暂停/继续**：讨论进行中「发送」原位变「暂停」（`aria-label` 同步）；点后显示「已请求暂停，当前这位说完就停」，下一位不启动；接口失败显示「暂停没成功，这位说完会停」（前端照样停）。暂停后按钮变「继续」，接着请剩下的成员。服务端 `POST /api/room/<id>/pause {paused}`（kv `pause:<room>`），`runTurn` 遇暂停直接返回 `paused`、不调模型；`/api/round` 循环遇暂停停止；用户发新消息或点「再来一轮」自动解除。MCP `pause_project`。
5. **N3 消息内决策按钮**：负责人 `POST /api/room/<id>/ask {question, options[2–3]}`（MCP `ask_user`）→ 房间里出现决策卡，2–3 个 ≥48px 按钮；用户点后整组禁用、写「你选了：X · 时间」、焦点移到结果文字。`POST /api/room/<id>/decide {msg, choice}` 只认网页/用户令牌（负责人和成员令牌不能替用户选）；**幂等**：条件更新 `… WHERE json_extract(v,'$.choice') IS NULL RETURNING`，重复点只记第一次（返回 `already:true`），「用户选择：X」只写进房间一次。
6. **L7 模式说明**：模式弹层改成单选组（`role=radiogroup/radio`、`aria-checked`、方向键移动焦点），5 个模式各一句可见说明（19px）、图标各不相同（`aria-hidden`），当前项写「✓ 当前」。说明文字也通过 `/api/members` 的 `modeInfo` 给负责人。
